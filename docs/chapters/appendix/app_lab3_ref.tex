\section*{Lab Startup Checklist}

\begin{enumerate}
    \item Start all nodes from the EVE-NG web interface in order:
          pfSense $\to$ VyOS $\to$ Server-Web $\to$ Server-DB.
    \item Verify the EVE-NG host bridge interfaces are active (persistent via
          \texttt{udev} rule \texttt{99-lab3-bridges.rules}):
\begin{lstlisting}[language=bash]
ip addr show vnet0_2   # Should show 192.168.50.254/24
ip addr show vnet0_3   # Should show 192.168.60.254/24
\end{lstlisting}
    \item If bridges are missing (e.g.\ after EVE-NG host reboot), restore manually:
\begin{lstlisting}[language=bash]
ip addr add 192.168.50.254/24 dev vnet0_2
ip addr add 192.168.60.254/24 dev vnet0_3
\end{lstlisting}
    \item Verify evidence artefacts are in place on both servers:
\begin{lstlisting}[language=bash]
# Server-Web (via SSH -- teacher account)
ssh ubuntu@192.168.50.10   # password: ubuntu
grep "185.220.101.47" /var/log/auth.log | wc -l  # expect 25+ lines
grep "maint" /etc/passwd  # expect maint entry
# Server-DB (via SSH -- teacher account)
ssh ubuntu@192.168.60.10   # password: ubuntu
ls /opt/helix/data/        # expect clients.db + .exfil_marker
\end{lstlisting}
    \item \textbf{Note:} If Lab~1 is also deployed, udev rules
          \texttt{99-lab1-bridges.rules} and \texttt{99-lab3-bridges.rules}
          assign overlapping interface names (\texttt{vnet0\_2}/\texttt{vnet0\_3}).
          Do not run Lab~1 and Lab~3 simultaneously on the same EVE-NG host.
\end{enumerate}

\section*{Student Entry Point}

Students connect via SSH to pfSense's WAN IP; pfSense DNAT forwards TCP~22 directly to
Server-Web:

\begin{lstlisting}[language=bash]
ssh analyst@<pfSense-WAN-IP>
# Password: An@lyst2024
# Lands on: analyst@helix-web:~$
\end{lstlisting}

No offensive tools are required. Students use only standard Unix utilities:
\texttt{grep}, \texttt{awk}, \texttt{less}, \texttt{cat}, \texttt{find},
\texttt{journalctl}.

\section*{Lab Reset Procedure}

To restore the lab to its initial forensic state after a student session:

\noindent Revert both Server-Web and Server-DB QCOW2 images from
the pre-staged backup stored at \path{/opt/unetlab/addons/qemu/lab3-backups/}.
